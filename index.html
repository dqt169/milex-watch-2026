Xuất bản Trang web MilEx Watch 2026 lên Internet

Hỗ trợ triển khai miễn phí qua GitHub Pages (kèm GitHub Actions tự động quét 2 giờ/lần), Netlify Drop hoặc Cloudflare Pages

Cách 1: Kéo - Thả lên Netlify Drop (Nhanh nhất — 30 giây)

  1. Tải gói milex_watch_2026_publish_bundle.zip đính kèm trong cuộc trò chuyện (hoặc nhấn nút tải index.html ở trên).
  2. Mở trang app.netlify.com/drop hoặc Cloudflare Pages.
  3. Kéo thả file ZIP vào ô Upload để nhận ngay đường link công khai https://...netlify.app hoạt động trên mọi thiết bị.

Cách 2: Xuất bản lên GitHub Pages + Tự động quét ngầm 2 giờ/lần (24/7)

Giải nén gói milex_watch_2026_publish_bundle.zip và đẩy lên một Repository GitHub mới (ví dụ trên tài khoản GitHub của bạn), sau đó vào Settings → Pages → Source: GitHub Actions. File cấu hình .github/workflows/deploy_and_crawl.yml dưới đây sẽ tự động chạy mỗi 2 giờ (cron: "0 */2 * * *") để cập nhật dữ liệu và xuất bản lại trang web: 

name: Auto-Crawl Military Exercises (Every 2 Hours) & Deploy GitHub Pages
on:
  push:
    branches: ["main"]
  schedule:
    - cron: "0 */2 * * *"
  workflow_dispatch:
permissions:
  contents: write
  pages: write
  id-token: write
jobs:
  crawl-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.11"
      - run: python3 scripts/update_exercises.py
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v3
        with:
          path: "."
      - uses: actions/deploy-pages@v4
